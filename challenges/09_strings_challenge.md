# Challenge: Strings

## Task

Write a program that:

1. Takes a sentence
2. Counts how many words it has
3. Prints the sentence in reverse word order
4. Makes every word start with uppercase

## Example

Input: `hello world from python`

Output:
```
Words: 4
Reversed: python from world hello
Title: Hello World From Python
```

Implement in as many languages as you can.
