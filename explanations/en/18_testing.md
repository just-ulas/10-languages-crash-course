# 18 - Testing

Every language has a preferred way to test:

| Language   | Tool / style              |
|------------|---------------------------|
| Python     | pytest / unittest         |
| JavaScript | jest / node:test          |
| Go         | `go test` + `_test.go`    |
| Rust       | `#[test]` + `cargo test`  |

Start with tiny self-checks. Graduate to real frameworks later.
