# 09 - Strings

Strings are sequences of characters.

Common operations across languages:
- Upper / lower case
- Length
- Slicing / substring
- Contains / starts with
- Interpolation (putting variables inside text)

## Key differences

- Python: f-strings are very readable
- JavaScript / TypeScript: template literals with backticks
- Go / Rust / Java / C#: more explicit formatting or concatenation
- C++: `std::string` + algorithms

Look at the code examples in each language folder to compare.
