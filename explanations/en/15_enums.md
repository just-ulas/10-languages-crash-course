# 15 - Enums

Enums let you define a fixed set of named values.

## Support

| Language   | Native enums? |
|------------|---------------|
| Python     | Yes (`enum`)  |
| TypeScript | Yes           |
| Java       | Yes           |
| C#         | Yes           |
| Rust       | Yes (powerful)|
| Go         | iota pattern  |
| JavaScript | Object.freeze |

Rust enums are especially powerful (can hold data).
