# 01 - hello world

the first thing everyone does in any language is printing something to the screen.

here we show how to print "hello" in different programming languages.

- python → print()
- javascript → console.log()
- go → fmt.Println()
- rust → println!()
- java → System.out.println()

basically we tell the computer: show this text.

check the code examples in the language folders.
