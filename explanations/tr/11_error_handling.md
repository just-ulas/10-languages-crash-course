# 11 - Hata Yönetimi

Diller hataları çok farklı şekilde ele alır.

## Stiller

| Dil        | Stil                         |
|------------|------------------------------|
| Python     | try / except / finally       |
| JavaScript | try / catch / finally        |
| Go         | açık `if err != nil`         |
| Rust       | Result / Option + `?`        |
| Java / C#  | try / catch + exception      |

Go ve Rust seni hatayı ele almaya zorlar.  
Python ve JS'de yok sayabilirsin.

Kod örneklerine bakarak farkı hisset.
