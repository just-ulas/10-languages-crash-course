# 01 - hello world

her dilde ilk yapılan şey ekrana bir şey yazdırmaktır.

burada farklı programlama dillerinde "hello" yazdırmayı görüyoruz.

- python → `print()`
- javascript → `console.log()`
- go → `fmt.Println()`
- rust → `println!()`
- java → `System.out.println()`

kısaca: bilgisayara "şunu ekrana bas" diyoruz.

kod örnekleri için ilgili dil klasörlerine bak:
`python/01_hello.py`, `javascript/01_hello.js` vs.
