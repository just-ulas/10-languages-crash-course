# 18 - Test

Her dilin tercih ettiği test yolu farklı:

| Dil        | Araç / stil               |
|------------|---------------------------|
| Python     | pytest / unittest         |
| JavaScript | jest / node:test          |
| Go         | `go test` + `_test.go`    |
| Rust       | `#[test]` + `cargo test`  |

Önce küçük self-check yaz. Sonra gerçek framework'e geç.
