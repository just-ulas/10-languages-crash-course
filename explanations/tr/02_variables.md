# 02 - değişkenler

değişken = bir değere isim vermek.

örnek:
- isim = "ulas"
- yaş = 20

bazı diller tip belirtmeni ister (java, go, rust, typescript),
bazıları otomatik anlar (python, javascript, ruby).

değişkeni sonradan değiştirebilirsin (çoğu dilde).
const / final gibi şeyler sabittir, değişmez.

kodlara bak:
`python/02_variables.py`
`javascript/02_variables.js`
`go/02_variables.go`
