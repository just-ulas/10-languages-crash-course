# 09 - Stringler

String = karakter dizisi.

Çoğu dilde ortak işlemler:
- Büyük / küçük harf
- Uzunluk
- Dilimleme (slice / substring)
- İçinde var mı? ile mi başlıyor?
- Değişkenleri metnin içine gömme

## Farklar

- Python → f-string çok okunaklı
- JavaScript / TypeScript → backtick ile template literal
- Go / Rust / Java / C# → daha açık formatlama
- C++ → `std::string` + algoritmalar

Kod örneklerini dil klasörlerinde karşılaştır.
